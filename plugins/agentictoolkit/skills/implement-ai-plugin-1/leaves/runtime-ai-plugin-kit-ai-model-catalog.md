# AIModelCatalog

## Overview

`AIModelCatalog` is the shared model table `AIPluginKit` ships as a bundled
resource (`model-catalog.json`): one `Model` entry per canonical model id,
independent of which gateway serves it, plus a per-`(templateId, spelling)`
`Offering` table for the terms (context window, output limit, token prices)
that genuinely differ between gateways. It is a **logic** component — no
visual surface — used by every `AIPluginDescriptor.ProviderTemplate` to answer
"what do we know about this model, and what does this gateway charge for it."
`resolve(model:template:)` merges the shared `Model` facts, the matching
`Offering`, and a template's curated `ModelDetail` into one `ResolvedModel`
for display. The catalog is generated by
`AIPlugins/tools/generate_model_catalog.py` from adh's public catalog and
committed as `AIPluginKit/model-catalog.json`; `AIModelCatalog.shared` loads it
once, falling back to an empty (never nil) catalog if the resource is missing
or unreadable.

## Behavioral Requirements

- **model-identity**: A `Model` MUST be uniquely identified by its canonical
  `id`; its `aliases` array MUST list every additional spelling a gateway uses
  for that same model (e.g. `meta-llama/Llama-3.3-70B-Instruct`,
  `@cf/meta/llama-3.3-70b-instruct-fp8-fast`).
- **model-decoding-defaults**: Decoding a `Model` MUST default `aliases` and
  `capabilities` to empty arrays and `description` to `nil` when those keys
  are absent from the JSON payload, rather than failing to decode the entry.
- **offering-is-per-gateway-spelling**: An `Offering` MUST be looked up under
  the exact model-name spelling that one gateway (`templateID`) uses; the same
  model's terms at a different gateway, or under its canonical id, MUST NOT be
  returned.
- **offering-fields-independently-optional**: Each field of `Offering`
  (`contextWindow`, `maxOutput`, `inputCostPerM`, `outputCostPerM`) MUST be
  independently representable as absent (`nil`) rather than defaulted to
  zero, because "unknown" and "zero" are different facts about a gateway's
  terms.
- **lookup-resolution-order**: `model(named:)` MUST resolve a name by
  exact-case match against `byName` first, THEN by lowercased match against
  `byName`, THEN by canonicalizing the name and matching `byCanonicalID`; it
  MUST return `nil` when none of the three match.
- **canonicalization-strips-namespace**: `canonicalID(_:)` MUST trim leading
  and trailing whitespace/newlines, lowercase the result, and drop any path
  segment up to and including the last `/`.
- **canonicalization-strips-free-suffix**: `canonicalID(_:)` MUST strip a
  trailing `:free` suffix (an OpenRouter price tier, not a different model).
- **canonicalization-strips-quantization-suffix**: `canonicalID(_:)` MUST
  strip at most one trailing suffix from the fixed set `-fp8-fast`, `-fp8`,
  `-fp4`, `-bf16`, `-awq`, `-int8`, `-int4`, testing them in that order so
  `-fp8-fast` matches before the shorter `-fp8` can.
- **canonicalization-preserves-other-suffixes**: `canonicalID(_:)` MUST NOT
  strip a suffix outside the quantization set — `-turbo`, `-latest`, `-fast`,
  `-thinking` MUST survive unchanged, because they name a genuinely different
  model or alias, not a precision variant.
- **resolve-merges-three-sources**: `resolve(model:template:)` MUST merge, for
  one `(model name, template)` pair, the shared `Model` facts (via
  `model(named:)`), the `Offering` for `template.id` under the given spelling
  (via `offering(templateID:model:)`), and the template's curated
  `ModelDetail` (via `template.modelDetail(for:)`, an exact-id match) into one
  `ResolvedModel`.
- **curated-description-wins**: `resolve(model:template:)` MUST use the
  curated `ModelDetail.description` when it is present and non-empty, and
  MUST fall back to the shared `Model.description` when the curated value is
  absent or an empty string.
- **curated-tools-wins**: `resolve(model:template:)` MUST use the curated
  `ModelDetail.tools` value when present; when absent, it MUST derive `tools`
  from whether the shared `capabilities` array contains `"tools"`, yielding
  `nil` (unknown), not `false`, when `capabilities` is empty.
- **terms-never-curated**: `resolve(model:template:)` MUST take
  `contextWindow`, `maxOutput`, `inputCostPerM`, and `outputCostPerM` only
  from the resolved `Offering`; the template's curated `ModelDetail` MUST NOT
  influence any of these four fields.
- **unknown-model-resolves-empty**: `resolve(model:template:)` MUST return a
  `ResolvedModel` (with `id` set to the requested name and `isEmpty == true`)
  for a name with no matching `Model` and no matching `Offering`, rather than
  returning `nil` or throwing.
- **shared-catalog-never-fails-to-exist**: `AIModelCatalog.shared` MUST always
  yield a usable, non-optional catalog: an empty catalog (`schemaVersion: 0`,
  no models, no offerings) whenever the bundled resource is missing,
  unreadable, or fails to decode.
- **load-is-total**: `load(from:)` MUST return `nil` — never throw — when the
  given bundle has no `model-catalog.json` resource, when the resource's
  `Data` cannot be read, or when the JSON fails to decode as
  `AIModelCatalog`.
- **index-built-at-init**: Every initializer MUST build `byName` and
  `byCanonicalID` synchronously from `models` during initialization, so
  `model(named:)` and `offering(templateID:model:)` are dictionary lookups
  and never re-scan `models`.
- **alias-collision-last-writer-wins**: When two `Model` entries in `models`
  share the same alias or the same `id` spelling as another entry's alias,
  `byName` MUST hold whichever model appears later in the `models` array for
  that spelling, because index population iterates `models` once, in array
  order, and later dictionary assignments overwrite earlier ones for the same
  key.
- **codable-round-trip-excludes-indexes**: Encoding and decoding an
  `AIModelCatalog` MUST round-trip only `schemaVersion`, `generatedAt`,
  `models`, and `offerings`; the private `byName`/`byCanonicalID` indexes MUST
  NOT appear on the wire and MUST be rebuilt from `models` on every decode.
- **value-type-is-freely-shared**: `Model`, `Offering`, `ResolvedModel`, and
  `AIModelCatalog` MUST be `Sendable` value types with no mutable state after
  initialization, so one loaded catalog instance MAY be read concurrently
  from any isolation domain without additional synchronization.
- **bundle-token-is-an-anchor-only**: `BundleToken` MUST exist solely so
  `Bundle(for: BundleToken.self)` resolves to this framework's own bundle
  regardless of which app embeds it; it carries no state and MUST NOT be used
  for anything but that one `Bundle(for:)` call.
- **schema-version-not-gated**: `AIModelCatalog.schemaVersion` MUST be decoded and stored but MUST NOT gate loading: no code reads or range-checks it, so any JSON-decodable payload loads whatever its `schemaVersion`, unlike the sibling `AIPluginDescriptor.schemaVersion`, which `AIPluginManager.swift` checks against `2...AIPluginDescriptor.currentSchemaVersion` and logs and skips when out of range. The catalog is a resource the framework ships itself, generated by `generate_model_catalog.py`, so a port that adds a range check is extending the contract, not restoring it.

## Configuration

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `bundle` | `Bundle` | `Bundle(for: BundleToken.self)` | Passed to `load(from:)`; the bundle to read `model-catalog.json` from. Tests override it (e.g. `Bundle(for: NSNull.self)`) to simulate a missing resource. |
| `model-catalog.json` | bundled resource | `packages/apple/AgenticToolkit/AIPluginKit/model-catalog.json` | Fixed resource filename, not configurable per call. Regenerated by `generate_model_catalog.py`; never hand-edited. |
| `schemaVersion` | `Int` | `0` for the empty fallback catalog; `1` in the shipped resource | Carried on the payload and on `AIModelCatalog()`'s private empty init; not validated at load time (see `schema-version-not-gated`). |
| `models`, `offerings` | `[Model]`, `[String: [String: Offering]]` | `[]`, `[:]` | Constructor parameters for building a catalog directly via `init(schemaVersion:generatedAt:models:offerings:)`, bypassing bundle loading entirely — the path the test suite's `sample` catalog and `AIModelCatalog()`'s empty fallback both use. |
